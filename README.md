An entry for the [make.fun](https://make.fun) bounty
[The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1):
a program that writes the funniest single-line resignation letter it can.

## Run

```sh
python3 main.py
```

The program writes one line — a one-line resignation letter from an IT
support technician who has spent a decade turning things off and on again —
to `/output/entry.txt` (override with `ENTRY_OUTPUT` for local testing).
The line is 1–140 characters, exactly one line, with no trailing newline.

## The line

> I hereby resign: after ten years of turning it off and on again, I have found the one thing that won't restart — me.
